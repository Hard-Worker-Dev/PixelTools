# PixelTools Support

## Report a bug

Use the GitHub bug report form:
https://github.com/Hard-Worker-Dev/PixelTools/issues/new?template=bug_report.yml

Include the tool name, exact reproduction steps, expected and actual behavior, browser/version, operating system and device type.

Use a non-sensitive sample image only. Never attach private, confidential or personally identifying images. Do not publish passwords, access tokens, private URLs or personal information in an issue.

## Request a feature

Use the feature request form:
https://github.com/Hard-Worker-Dev/PixelTools/issues/new?template=feature_request.yml

Explain the desired workflow, output and any relevant format or dimension requirements.

## Privacy questions

Do not post personal or sensitive information in a public issue. Review the Privacy Policy and contact the repository maintainer through the repository's GitHub contact route:
https://pixeltools-9xe.pages.dev/privacy/

## Security vulnerabilities

Do not report exploitable security details in a public bug report. Follow SECURITY.md and use GitHub's private vulnerability reporting flow when it is enabled for the repository.
