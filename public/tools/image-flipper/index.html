How to use Image Flipper

Upload an image, select horizontal or vertical flip, choose an output format and download the processed image.

Images are processed in your browser for this tool. PixelTools does not upload your selected image to its own image-processing server.

Frequently asked questions

What is a horizontal flip?

A horizontal flip mirrors the image from left to right. A vertical flip mirrors it from top to bottom.

Will the original file change?

No. The tool generates a separate output image.
