Image Color Picker

Sample individual pixels from an image and read their HEX and RGB color values. The sampling is performed locally in your browser.

Open Image Color Picker →

How to use Image Color Picker

Upload an image and click the pixel you want to sample. Copy the HEX code or read its RGB channels.

Images are processed in your browser for this tool. PixelTools does not upload your selected image to its own image-processing server.

Frequently asked questions

Does it sample the original pixel?

Yes. PixelTools maps the preview click back to the original image coordinates before sampling.

Can I copy the HEX value?

Yes. Use the copy button when clipboard access is available, or select the displayed value manually.
