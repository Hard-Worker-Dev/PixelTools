How to use Image Watermark

Select an image, enter a short watermark, adjust opacity, select output format and process the image.

Images are processed in your browser for this tool. PixelTools does not upload your selected image to its own image-processing server.

Frequently asked questions

Can I change watermark opacity?

Yes. The tool provides an opacity slider so you can make the text more or less visible.

Can I add an image logo?

This initial version adds text watermarks. Image-logo overlays are not included yet.
