Image Resizer

Resize images to exact pixel dimensions with an in-browser image resizer. Set a custom width and height and export a new JPG, PNG or WebP file.

Open Image Resizer →

How to use Image Resizer

Choose an image, enter the desired width and height in pixels, process it and save the resized copy.

Images are processed in your browser for this tool. PixelTools does not upload your selected image to its own image-processing server.

Frequently asked questions

Can I set exact dimensions?

Yes. Enter whole-number width and height values. The current tool accepts up to 12,000 pixels on each side.

Are my originals overwritten?

No. PixelTools creates a new downloadable file and leaves your source file unchanged.
