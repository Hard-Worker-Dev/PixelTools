CONTACT & SUPPORT

Let's make PixelTools better.

Found a bug, need help with a tool, or have an idea for a useful image workflow?

Report an issue or request a feature

Use the public GitHub repository to report a non-sensitive problem or suggest an improvement. Include the browser and device details, the tool name and the steps needed to reproduce an issue. Do not attach private or sensitive images, personal data, passwords or confidential material to a public issue.

Open PixelTools on GitHub →

Privacy questions and requests

Review the Privacy Policy first. The project does not currently publish a dedicated private privacy-request email or private request form. Do not place personal information or confidential requests in public issues. The project owner must publish a monitored private contact route before broad public launch.

Security vulnerabilities

Please do not disclose suspected vulnerabilities in public issues. Use GitHub's private security advisory reporting route if private vulnerability reporting is enabled for the repository. Do not include real user images or personal data in a report.
